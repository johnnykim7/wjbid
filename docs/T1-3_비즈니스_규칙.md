# SAM.gov Bidding Agency Platform 비즈니스 규칙 정의서

> 설계 버전: 1.0 | 최종 수정: 2026-03-19 | 관련 CR: -

> 단계: 1. Requirements | 실행스펙에 포함
>
> **비즈니스 규칙 = 변하지 않는 핵심 규칙. 코드에 고정.**
> 변경 가능한 규칙은 T1-4(정책 정의)에 작성한다.

---

## 규칙 목록

| 규칙 ID | 영역 | 규칙 | 상세 설명 / 예외 | 우선순위 |
|---------|------|------|-----------------|---------|
| BIZ-001 | 상태 관리 | FSM 화이트리스트 방식 | 허용 전이 목록에 없는 상태 전이는 전면 차단. 정의되지 않은 전이 = 거부. | High |
| BIZ-002 | 문서 | 문서 버전 불변성 | 한번 생성된 문서 버전은 수정/삭제 불가. 변경 시 새 버전 생성. 감사 추적 목적. | High |
| BIZ-003 | 문서 | LOCKED 문서 편집 불가 | 잠금(LOCKED) 상태의 문서는 내용 수정 불가. 증거 보존 목적. | High |
| BIZ-004 | 공고 수집 | 원본 JSON 보존 | SAM.gov에서 수집한 원본 JSON은 변경하지 않고 그대로 보존. 감사/추적용. | High |
| BIZ-005 | 공고 수집 | 콘텐츠 해시 중복 검출 | 동일 콘텐츠 해시의 공고는 신규 삽입하지 않고 갱신 처리. | High |
| BIZ-006 | 입찰 | 동일 공고 중복 신청 불가 | 한 고객이 동일 공고에 대해 중복 입찰 신청 불가. | High |
| BIZ-007 | 컴플라이언스 | BLOCKER 미충족 시 제출 차단 | is_blocker=true인 요구사항이 미충족이면 READY_FOR_SUBMISSION 전이 차단. | High |
| BIZ-008 | 인증 | 이메일 유일성 | 동일 이메일로 중복 회원가입 불가. | High |
| BIZ-009 | 문서 | 잠금은 DRAFT에서만 가능 | DRAFT 상태의 문서만 LOCKED로 전환 가능. 이미 LOCKED/ARCHIVED는 재잠금 불가. | Medium |
| BIZ-010 | 템플릿 | 사용 중 템플릿 삭제 불가 | 입찰 건에서 참조 중인 템플릿은 삭제 불가. 비활성화만 허용. | Medium |
| BIZ-011 | 첨부문서 | 파일 크기 제한 | 업로드 파일은 50MB 이하로 제한. | Medium |
| BIZ-012 | 알림 | 알림 중복 발송 방지 | 동일 이벤트에 대해 동일 알림을 중복 발송하지 않음 (멱등성). | Medium |
| BIZ-013 | MCP | MCP 응답 무상태 | MCP Tool 호출은 무상태(stateless). 각 호출은 독립적으로 처리. | Medium |
| BIZ-014 | 자격 진단 | 진단 결과 비보증 | 자격 진단 결과는 참고용. 법적 보증 아님. 면책 고지 필수. | Medium |
| BIZ-015 | 컴플라이언스 | 요구사항 슬롯 충족 게이트 (CR-010) | DOCS_PENDING → DOCS_RECEIVED 전이는 공고의 BLOCKER 요구사항 슬롯이 모두 ClientDocument/DocumentSection/Attachment 중 하나로 충족된 상태여야 허용. 미충족 시 전이 차단 + 미충족 슬롯 목록 반환. | High |
| BIZ-016 | 성공 제안서 패턴 | 패턴 추출은 공고유형 단위 (CR-013-R 개정) | **개정 (2026-05-29, CR-013-R)**: 슬롯 단위 폐기 → **공고유형 단위**로 수행. 해당 유형에 성공 제안서 1건 이상이면 추출 허용(1건으로 가이드 v1, 새 건 등록 시 누적 갱신). 구 규칙(슬롯 2건 이상 가드)은 슬롯 폐기로 무효. | High |
| BIZ-017 | 성공 제안서 패턴 | 가이드 출처 보호 (CR-013) | PatternGuide의 source가 HUMAN_EDITED/HUMAN_ADDED인 가이드는 AI 자동추출이 덮어쓰지 않음. 재추출은 source=AI_EXTRACTED인 가이드만 갱신. 전문가가 직접 편집한 노하우 보존 목적. | High |
