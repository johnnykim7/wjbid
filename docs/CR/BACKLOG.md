## BL-001 · 고객 포털 비밀번호 재설정 기능

| | |
|---|---|
| 등록일 | 2026-10-10 |
| 출처 | CR-131 로그인·회원가입 화면 개편 중. 로그인 화면의 "비밀번호 찾기" 링크가 아무 데로도 가지 않았다(frontend/customer-portal/src/pages/LoginPage.tsx:101, href="#"). 사용자 10/10 22:41 /전승으로 CR-131 에서는 고객센터 이메일 안내 문구로 바꾸고, 재설정 기능 신설은 백로그로 둔다 |
| 담당(예정) | bidding-agency-platform |
| 상태 | 대기 |

**무엇**

고객이 비밀번호를 잊었을 때 스스로 다시 설정할 길이 없다. CR-131 뒤에는 로그인 화면이 고객센터 이메일로 가입 이메일을 보내 달라고 안내하고, 운영자가 손으로 처리한다. 메일로 재설정 링크를 보내 고객이 직접 새 비밀번호를 정하는 기능이 필요하다. 백엔드(재설정 토큰, 만료, 한 번만 쓰기, 메일 양식)와 고객 화면(재설정 요청, 새 비밀번호 입력)이 함께 걸린다.

**왜 남겼나**

새 API 와 메일 양식, 화면이 들어가는 중규모 이상이라 T1 부터 캐스케이드가 필요해 화면 개편(CR-131)과 떼었다. 1:1 문의 화면도 아직 서버에 닿지 않아(pages/SupportPage.tsx, 제출이 알림창만 띄움) 안내처로 쓸 수 없다. 가입 회원이 늘어 이메일 문의로 감당하기 어려워지기 전에 한다.
