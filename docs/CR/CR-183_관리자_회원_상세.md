# CR-183 관리자 회원 상세

> 설계 버전: 0.2 | 최종 수정: 2026-10-26 | 관련 CR: CR-157, CR-182

- CR-ID: CR-183
- 작성일: 2026-10-26
- 규모: 중 (관리자 화면에 상세 창과 수정 추가, API 2개 신설, 내 프로필 수정 1칸 추가, 데이터 변화 없음)
- 상태: 구현, 로컬 확인 끝(10/26 22:58). 상용 배포는 CR-182 다음

## 1. 실측 (2026-10-26 develop 소스)

- 회원 관리 목록은 이메일, 회사명, 담당자, 역할, 회원, 가입일, 최근 로그인 7칸이다. 줄 끝 단추는 고객 줄에만 있고 회원 기간 창만 연다(`MemberAdminPage.tsx`)
- 목록 응답(`GET /admin/members`)은 전화번호를 싣지만 화면에 칸이 없다(`MemberAdminController.java` 의 MemberDto)
- 가입 때 넣는 사업자등록번호, 내 프로필에서 넣는 주소, 이메일 확인 시각은 저장되지만 관리자 응답에 없다(`Member.java`, `MemberService.java` createCustomer)
- 관리자가 회원 정보를 고치는 API 와 화면이 없다(`MemberAdminController.java` 는 목록 조회와 회원 기간만)
- 고객 내 프로필에는 사업자등록번호 입력칸이 있지만 저장할 때 보내지 않고(`ProfilePage.tsx` handleSave), 서버도 받지 않는다(`MemberController.java` UpdateProfileRequest, `MemberService.updateProfile`). 고쳐도 남지 않는다
- UEI, CAGE 칸은 표에 있지만 넣는 화면과 서버 처리가 없어 늘 비어 있다. 상세에 넣지 않는다
- CR-182 가 회원 관리 화면을 디자인시스템 부품으로 다시 그렸고(브랜치 `feat/cr182-admin-ds` 1c67c43), develop 에는 아직 없다

## 2. 고칠 곳

| 순번 | 자리 | 지금 | 바꾼 뒤 |
|------|------|------|--------|
| 1 | 서버 | 회원 한 명을 보는 관리자 조회가 없다 | `GET /admin/members/{memberId}` 를 더한다. 가입 정보와 지금 기간 끝일을 준다. 없는 회원은 404 `MEMBER_NOT_FOUND` |
| 2 | 회원 관리 목록 | 고객 줄 끝 "회원 기간" 단추 | 모든 줄 끝 "상세" 단추로 회원 상세 창을 연다 |
| 3 | 회원 상세 창 | 없음 | 위에 회원 정보, 아래에 지금의 회원 기간 넣기와 기간 이력. 관리자 줄은 회원 정보만 |
| 4 | 서버 | 관리자 수정이 없다 | `PATCH /admin/members/{memberId}` 로 회사명, 사업자등록번호, 담당자, 전화번호, 주소를 통째로 바꾼다. 회사명 빈 칸 400, 없는 회원 404 |
| 5 | 회원 상세 창 | 보기만 | 회원 정보 제목 옆 "수정" 으로 다섯 칸을 입력칸으로 바꾸고 저장, 취소 |
| 6 | 고객 내 프로필 | 사업자등록번호가 저장되지 않는다 | 화면이 싣고 서버가 저장한다. 보내지 않으면(옛 화면) 그대로 둔다 |

## 3. 결정

- 상세는 목록 위에 뜨는 창으로 연다. 목록을 떠나지 않아 페이지와 스크롤 위치가 그대로다
- 관리자는 회사명, 사업자등록번호, 담당자, 전화번호, 주소를 고친다. 회사명은 비울 수 없고(표에서 필수) 나머지는 비우면 지운다. 이메일(로그인 아이디, BIZ-008)과 역할은 고치지 않는다
- 고객 내 프로필의 사업자등록번호는 보내지 않으면 그대로 둔다. 배포 직후 옛 화면을 연 고객이 저장해도 지워지지 않게 하려는 것이다
- 회원 기간 창은 회원 상세 창의 아래 영역이 되고 따로 남지 않는다
