- 상태: 설계. 화면 컨셉은 3(실화면 목업 방향 그대로 구현), 구현은 CR-170 수정, CR-179, CR-181 이 develop 에 들어간 뒤 그 위에서 시작한다(사용자 10/26 06:30 /전승)

## 1. 배경

사용자가 CR-179 실화면 목업을 보다가 관리자 화면 아이콘이 AI 가 만든 인상이고 글자가 작다고 했고, BO2 를 본떠 관리자 화면을 고치라고 했다(05:02). 디자인시스템을 흉내 낸 마크업이 아니라 부품을 실제로 import 해 쓰는 것이고(05:27), 왼쪽 메뉴는 그대로 두고 표 같은 공용 부품을 바꾸는 것이다(05:42, 05:43). 개선안 목업을 보고 방향을 확정했다(06:03).

### 2.2 디자인시스템 연결

- ds-ui 0.3.0 이 `file:` 링크로 연결돼 있고(`package.json`), `main.tsx` 가 `dist/style.css`, `dist/themes/wjbid-admin.css`, Toaster 를 불러온다
- ds-ui DataGrid 는 피어 의존성 `@tanstack/react-table` 이 필요한데 관리자 콘솔에 없다. Table 묶음(Table, TableHeader, TableBody, TableRow, TableHead, TableCell)은 필요 없다
- `lucide-react` 는 ds-ui 의 의존성이고 관리자 콘솔의 직접 의존성이 아니다. 화면에서 import 하려면 관리자 콘솔 `package.json` 에 있어야 한다. 고객 포털은 `^0.575.0` 이다
- Tailwind v4 에서 `index.css` 의 기본 초기화가 ds-ui CSS 뒤에 와서 선 색이 글자색(검정)으로 돌아가고, ds-ui 부품이 쓰는 클래스(`border-border` 등)가 이 앱 CSS 에 생기지 않는다(목업 실측)
- `index.css` 의 `--color-accent` 잇기가 디자인시스템 강조색을 관리자 초록으로 덮는다. 화면에서 `accent` 색 클래스를 쓰는 곳은 없다(`accent-secondary` 는 체크 상자 색 지정이라 별개)
- 관리자 테마의 `--secondary` 가 파랑이라 ds-ui `Badge variant="secondary"` 가 파랗게 나온다

### 2.3 실화면 목업 (2026-10-26)

- 상용 GET 응답을 녹화해 주고, 바뀔 화면만 개선안 사본으로 그린 「현재」, 「개선안」 두 탭. 소스 수정, 배포, 서버 쓰기 0건
- 개선안 사본의 변경분은 37개 파일이다(바탕 7548e6c, CR-179 브랜치 끝. 목업 폴더 `설계전_관리자BO2개편_20261026/관리자개편_목업.patch`)
- 목업 전용 임시 처리가 있다. `lucide-react` 를 디자인시스템 설치본으로 별칭(vite alias, tsconfig paths)했고, 글꼴 파일을 사본에 복사했다. 구현은 이 처리를 쓰지 않는다
- 목업에 남은 것: em dash 와 화살표가 든 화면 문구(제안서 Section, 성공 제안서 패턴, 문서 양식), 브라우저 기본 확인 창과 알림

### 2.4 이미 있던 결함 (BACKLOG BL-003)

- 입찰 목록과 상세 API 는 공고 제목, 기관, 공고번호, 회원을 펼친 칸(`opportunityTitle`, `agencyName`, `solicitationNumber`, `memberEmail`, `displayTitle`)으로 주는데, 화면은 `opportunity`, `member` 묶음을 읽어 "-" 가 나온다. 목업은 펼친 칸을 읽게 했다
- 입찰 상세의 고객 제출 문서는 없는 주소 `/client-documents/{입찰 건 id}` 를 부른다(`api/client.ts:173`). 서버 주소는 `/bid-requests/{bidRequestId}/client-documents` 다(`ClientDocumentController.java:22`)
