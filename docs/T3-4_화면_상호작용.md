# SAM.gov Bidding Agency Platform 화면 상호작용 명세서

> 설계 버전: 1.4 | 최종 수정: 2026-10-11 | 관련 CR: CR-131, CR-132, CR-133, CR-135

> 단계: 3. Detail Design | FE/풀스택 프로젝트에서 작성
>
> T3-3(화면 구조)이 "무엇이 있는지"를 정의한다면,
> 이 문서는 "어떻게 동작하는지"를 정의한다.
> 모든 페이지를 작성하지 않는다 — 복잡한 인터랙션이 있는 페이지만 작성한다.

---

## 작성 대상

| 페이지 | 사유 |
|--------|------|
| 공고 상세 — 입찰 신청 | 다단계 흐름 (서비스 레벨 선택 → 신청) + 자격 진단 연동 |
| 입찰 상세 — 문서 업로드 | 파일 업로드 + 진행률 + 상태 자동 전이 |
| 문서 편집 (Admin) | TipTap 에디터 + 버전 관리 + 잠금/해제 + PDF 내보내기 |
| 입찰 상세 관리 (Admin) | FSM 상태 전이 UI + 조건부 액션 |
| 로그인·회원가입 (CR-131) | 칸별 입력 오류, 이미 가입된 이메일, 가입 직후 안내 |
| 고객센터 1:1 문의 (CR-132) | 비로그인 접수, 로그인 채움, 주소로 유형·제목 채움, 접수 실패 |
| 1:1 문의 관리 (Admin, CR-132) | 거르기와 돌아오기, 답변 메일 성공·실패, 이미 답변된 문의 |

## 공고 상세 — 입찰 신청 (`/search/{id}`)

### 진입 조건

- **인증**: 공고 열람은 불필요, 입찰 신청은 🔒 필요
- **권한**: CUSTOMER
- **선행 조건**: 없음 (공고 ID로 직접 접근 가능)
- **진입 불가 시**: 404 페이지 (공고 미존재)

### 데이터 로딩

| 순서 | API 호출 | 타이밍 | 실패 시 |
|------|---------|--------|--------|
| 1 | GET /opportunities/{id} | 페이지 진입 | 에러 메시지 표시, 목록으로 이동 유도 |
| 2 | GET /opportunities/{id}/requirements | 페이지 진입 | 요구사항 영역 빈 상태 표시 |
| 3 | GET /opportunities/{id}/attachments | 페이지 진입 | 첨부문서 영역 빈 상태 표시 |
| 4 | GET /bookmarks/{id}/status | 로그인 상태일 때 | 북마크 버튼 비활성 |

### 사용자 인터랙션 시나리오
