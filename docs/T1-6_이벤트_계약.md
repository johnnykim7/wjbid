## 내부 이벤트 (모듈 간)

### OpportunitiesCollected (v1)
- **트리거 조건**: SAM.gov 수집 완료 시 (신규 공고 1건 이상)
- **주요 포함 데이터**: collectionId, newCount, updatedCount, keyword, collectedAt
- **소비 주체**: 알림 모듈 (관리자 이메일 발송)
- **관련 기능 ID**: BID-OPP-001, BID-OPP-004

### AttachmentDownloaded (v1)
- **트리거 조건**: 공고 첨부문서 다운로드 완료 (또는 실패)
- **주요 포함 데이터**: opportunityId, attachmentId, fileName, fileSize, downloadStatus (SUCCESS/FAILED/LINK_ONLY), storageUrl
- **소비 주체**: 공고 열람 모듈 (첨부파일 표시 갱신)
- **관련 기능 ID**: BID-OPP-003

### BidRequestCreated (v1)
- **트리거 조건**: 고객이 입찰 참여 신청 완료 시
- **주요 포함 데이터**: bidRequestId, opportunityId, customerId, serviceLevel, createdAt
- **소비 주체**: 알림 모듈 (관리자 알림), 상태 관리 모듈
- **관련 기능 ID**: BID-REQ-001

### BidRequestStateChanged (v1) — 소비 확장 CR-018
- **트리거 조건**: BidRequest 상태 전이 실행 시
- **주요 포함 데이터**: bidRequestId, fromState, toState, changedBy, changedAt, notes
- **소비 주체**: 알림 모듈, AI 워크플로우 트리거 (ANALYZING/GENERATING 진입 시)
- **관련 기능 ID**: BID-FSM-001
- **CR-018 소비 추가 (고객 알림)**: 알림 모듈이 toState 기준으로 고객(BidRequest.member)에게 발송 —
  - `toState=REVIEW` → 제안서 생성 완료 알림 (BID-NOTIFY-003)
  - `toState=SUBMITTED` → 입찰 접수(제출) 완료 알림
  - `toState=AWARDED` → 입찰 합격 알림 (BID-NOTIFY-004)
  - 멱등 키: `BR_STATE_{bidRequestId}_{toState}`. 동일 전이 재발생 시 중복 발송 차단(BIZ-012).

### DocumentsReceived (v1)
- **트리거 조건**: 고객이 필요 문서 전부 제출 완료 시
- **주요 포함 데이터**: bidRequestId, documentCount, submittedAt
- **소비 주체**: 상태 관리 모듈 (DOCS_RECEIVED 전이), 알림 모듈
- **관련 기능 ID**: BID-REQ-002

### DocumentGenerated (v1)
- **트리거 조건**: AI 제안서 생성 완료 시
- **주요 포함 데이터**: bidRequestId, documentId, documentType, generatedAt
- **소비 주체**: 알림 모듈 (관리자 이메일), 상태 관리 모듈 (REVIEW 전이)
- **관련 기능 ID**: BID-DOC-001, BID-DOC-002

### DocumentConfirmed (v1)
- **트리거 조건**: 관리자가 문서 확정(LOCKED) 시
- **주요 포함 데이터**: bidRequestId, documentId, confirmedBy, confirmedAt
- **소비 주체**: 상태 관리 모듈 (CONFIRMED 전이)
- **관련 기능 ID**: BID-EDIT-002

### OpportunityAnalysisCompleted (v1) — CR-003
- **트리거 조건**: Aimbase 워크플로우가 공고 사전 분석을 완료 시 (성공 또는 실패)
- **주요 포함 데이터**: opportunityId, analysisId, status (COMPLETED/FAILED), analyzedAt
- **소비 주체**: 알림 모듈 (관리자에게 분석 완료 알림 — 검수 필요), 공고 관리 모듈 (OpportunityAnalysis 상태 갱신)
- **관련 기능 ID**: BID-OPP-006

### OpportunityApproved (v1) — CR-003
- **트리거 조건**: 관리자가 공고 사전 분석 결과를 검수하고 노출 승인 시
- **주요 포함 데이터**: opportunityId, approvedBy, approvedAt
- **소비 주체**: 공고 열람 모듈 (Opportunity.visibility → VISIBLE), 알림 모듈 (선택: 관심 고객에게 신규 공고 알림)
- **관련 기능 ID**: BID-OPP-008

### DeadlineApproaching (v1)
- **트리거 조건**: 스케줄러가 입찰 마감일 임박을 감지 시 (D-7, D-3, D-1)
- **주요 포함 데이터**: opportunityId, bidRequestId, deadline, daysRemaining
- **소비 주체**: 알림 모듈 (이메일 발송)
- **관련 기능 ID**: BID-NOTIFY-002

## 외부 연동 이벤트

### AimbaseWorkflowCompleted (v1)
- **트리거 조건**: Aimbase Workflow 실행 완료 (콜백 또는 폴링)
- **주요 포함 데이터**: workflowRunId, status (SUCCESS/FAILED), result, completedAt
- **발행 주체**: Aimbase → Bidding Platform
- **관련 기능 ID**: BID-DOC-001
- **정합성 전략**: 폴링 기반 (Aimbase API). Outbox 불필요
- **멱등 키**: workflowRunId
- **실패 처리**: 실패 시 관리자에게 알림. 수동 재시도 가능

### AimbaseToolCall (v1)
- **트리거 조건**: Aimbase가 MCP 프로토콜로 Bidding Platform의 Tool을 호출 시
- **주요 포함 데이터**: toolName, parameters (JSON), requestId
- **발행 주체**: Aimbase → Bidding Platform (MCP 서버)
- **관련 기능 ID**: BID-MCP-001~004
- **정합성 전략**: 요청-응답 방식 (동기). 트랜잭션 관리는 Tool 내부
- **멱등 키**: requestId
- **실패 처리**: MCP 에러 응답 반환. Aimbase가 재시도 판단

### SAMgovApiResponse (v1)
- **트리거 조건**: SAM.gov API 호출 응답 수신 시
- **주요 포함 데이터**: keyword, resultCount, opportunities[], responseAt
- **발행 주체**: SAM.gov API → 공고 수집 모듈
- **관련 기능 ID**: BID-OPP-001
- **정합성 전략**: HTTP 요청-응답. 실패 시 다음 수집 주기에 재시도
- **멱등 키**: 콘텐츠 해시 (중복 공고 검출)
- **실패 처리**: API 실패 로그 기록. 다음 스케줄에 자동 재시도
