## 4. 설계

### 4.1 화면 구조

T3-3 「공통 틀」, 「홈」, 「준비 중」 이 정본이다. 요지만 둔다.

- 상태 셋: 공고 0건(#s0), 공고 있음(#s1), 회원(#s2). 공고 수와 로그인 여부로 정한다.
- 첫 화면 1440x900 안에 마감 전 공고(또는 0건 안내), 오른쪽 첫걸음 상자(또는 회원 상자), 다섯 단계 띠가 들어간다.
- 아래 구역은 서비스, 회원 혜택, 요금, 도움 순으로 회색과 흰 띠를 번갈아 깐다.
- 홈은 너비 전체 띠를 쓰므로 공통 레이아웃의 본문 상자를 홈에서는 쓰지 않는다. 다른 화면의 본문 너비는 머리말과 맞춰 1200px.

### 4.2 색 이름표 (CR-128 계약)

T3-3 「고객 포털 색 이름표」 가 정본이다. 강조색 묶음 7개(brand, brand-strong, brand-soft, brand-softer, brand-deep, brand-line, brand-on-dark)만 바꾸면 색이 바뀐다. 나머지는 고정 색(글자 4단, 선 3단, 바탕, 어두운 면, 상태 색).

### 4.3 데이터

| 화면 값 | 출처 |
|---|---|
| 마감 전 공고 목록, 건수, 7일 안 마감 수 | 공개 공고 조회 (비로그인 가능) |
| 관심 공고 수, 입찰 신청 수, 안 읽은 알림 수 | 관심 공고, 내 입찰, 알림 조회 (로그인) |
| 회원 금액, 요금 세 칸 | CR-129 요금 출처. 홈에 금액을 박지 않는다 |
| 서비스 목록, 메뉴, 자주 묻는 질문, 공지사항, 예시 그림 | 화면 정의 파일 한 곳 (서비스 목록은 발주사 선택 뒤 바꾼다) |

## 5. 완료 조건

1. 로컬에서 홈 네 상태(공고 0건, 공고 있음, 회원, 전체메뉴 열림)를 1440x900 으로 캡처해 정본 캡처와 나란히 대조하고, 도구/measure8.js 와 같은 기준으로 잰 머리말 끝(192), 두 칸 끝(768, 회원 765), 다섯 칸 띠 끝(880, 회원 877)이 맞고 넘친 글자가 없다. 4.4 의 차이만 남는다.
2. 공통 틀이 홈 밖 화면(공고 검색, 요금 안내, 고객센터 등)에도 같은 모양으로 걸린다.
3. 강조색 묶음 7개를 차콜과 주황 값으로 바꿔 홈과 공통 틀이 함께 바뀌는 것을 로컬에서 확인하고 되돌린다.
4. 운영 배포(./deploy.sh fe)와 운영 화면 확인.
