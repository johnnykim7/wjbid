## 4. 설계

### 4.1 요금 체계

| 단계 | 결제 | 금액 | 포함 |
|------|------|------|------|
| 무료 | 없음 | 0원 | SAM.gov 공고 검색, 공고 한글로 보기(SAM 번역 수준), 관심 공고 저장, 입찰 신청, 입찰 교육 자료와 무료 입찰 교실 |
| 회원 | 월 구독 | 설정값 PRICING_MEMBER_MONTHLY_KRW (원, 부가세 별도). 비어 있으면 금액 대신 "요금 안내 준비 중" | 무료 전체 + 공고문 상세 번역(첨부 포함), 적격성 진단(우리 회사 맞춤 판정), 재발주 예측 달력, 새 공고 알림, 서류함과 제출 전 검사 |
| 대행·컨설팅 | 건별 견적 | 상담 후 견적 | SAM.gov·PIEE 등록 대행, 제안서 자문·검토(최종 제출과 서명은 고객), 현장 설명회 동행과 기지 출입 지원, 대금 청구 대행, 서류 영문 번역 |

단계 이름, 대상, 포함 항목은 CR-127 홈 시안 요금 구역과 같은 말을 쓴다.

### 4.2 데이터와 API

- 설정 테이블 `system_settings` (설정 키, 값, 설명, 수정 시각). 회원 금액 행은 값을 비운 채 마이그레이션으로 넣는다. 금액이 정해지면 그 행의 값만 채운다.
- `GET /pricing` (로그인 불필요) 응답: `{ "memberMonthlyPrice": 50000 }` 또는 `{ "memberMonthlyPrice": null }`. 값이 비었거나 숫자가 아니면 null.
- 고객 포털: 요금 조회 함수와 공용 훅을 두고, 요금 안내와 홈 요금 구역이 같이 쓴다. CR-127 에 [계약] 으로 알린다.

### 4.2.1 CR-127 과의 계약 (홈 요금 구역)

- 파일: frontend/customer-portal/src/hooks/usePricing.ts
- `usePricing()` 반환 `{ memberMonthlyPrice: number | null, loading: boolean }`
- 금액 자리: `memberMonthlyPrice` 가 null 이면 `MEMBER_PRICE_PENDING_LABEL`("요금 안내 준비 중"), 값이면 `formatWon(n)`("50,000원") 뒤에 "/ 월". 셋 다 같은 파일에서 export.
- 불러오는 동안(`loading`)은 금액 자리를 비우거나 옅게 둔다. 화면에 금액 숫자를 쓰지 않는다.

### 4.3 화면

화면 구조는 T3-3 「요금 안내 (`/pricing`) (CR-129)」「결제 내역 (`/billing`) (CR-129)」 에 있다. 아래는 문구가 바뀌는 화면의 초안이다. 약관과 환불 정책은 지금처럼 법무 검토 전 자리표시 문구다.

**이용약관 제2조 정의 (승인 뒤 같은 취지로 함께 고침)**

- "건당 과금" 정의를 지우고: "회원 월 요금"이란 회원 기능을 월 단위로 이용하는 요금을, "건별 요금"이란 대행·컨설팅 작업마다 상담 후 견적으로 정하는 요금을 말합니다.

**이용약관 제5조**

- 제목: 요금 및 결제
- 본문: 서비스 요금은 무료 이용, 회원 월 요금, 대행·컨설팅 건별 요금으로 나뉩니다. 회원 월 요금은 요금 안내 화면에 안내된 금액을 월 단위로 결제하며, 약정 없이 해지할 수 있습니다. 대행·컨설팅 요금은 상담 후 작업 착수 전에 견적으로 안내하며, 이용자가 결제를 완료한 시점에 작업이 개시됩니다. 환불 기준은 별도의 환불 정책에 따릅니다.

**환불 정책**

- 머리 설명: 회원 월 요금과 대행·컨설팅 건별 요금의 환불 기준을 안내합니다.

**결제 내역**

- 안내 띠: "회원은 월 단위, 대행·컨설팅은 건별 견적" / "회원 월 요금은 매달, 대행·컨설팅은 상담 후 견적에 따라 결제됩니다."

**이용 안내 자주 묻는 질문 "비용은 어떻게 되나요?"**

- 답: 무료와 회원 두 단계가 있고, 회원은 월 단위로 결제합니다. 등록 대행·제안서 자문 같은 대행·컨설팅은 상담 후 건별 견적으로 안내합니다. 자세한 내용은 요금 안내 화면에서 확인하세요.

**공지사항 더미 2번 "요금제 개편 안내 (Basic / Professional / Enterprise)"**
