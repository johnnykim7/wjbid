- 실제 자료를 보고 형식 판정을 좁혔다(BIZ-047). 원문이 형식 이름과 기호로만 되어 있을 때만 기계가 판정한다. "Excel sheet (PDF로 제출)" 을 Excel 도 맞음으로 보지 않으려는 것이다.
