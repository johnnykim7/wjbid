# CR-143 남의 입찰 건 막을 범위 승인요청 (2026-10-11)

막을 경로 목록은 [../CR-143_남의_입찰_건이_열리는_구멍_막기.md](../CR-143_남의_입찰_건이_열리는_구멍_막기.md) 3절에 있다. 고객이 부를 수 있는 곳이 13 곳이다.

- 로그인한 고객이 남의 건을 여는 곳 8: 입찰 건 상세, 다음 상태, 상태 이력, 문서 목록(제안서 본문), 상태 전환, 올린 서류 목록, 올리기, 지우기. 상태 전환, 올리기, 지우기는 남의 건을 바꾼다.
- 로그인 없이 열리는 곳 2 갈래: FlowGuard 확인용 통로 4(전체 입찰 건 번호 목록 포함), Aimbase 가 부르는 통로(입찰 건 조회, 제안서 입력, 상태 전환, 문서 저장 등 도구 20개).
- 규모 소: 새 API, 화면, 표가 없다. 있는 API 에 본인 확인과 "찾을 수 없음" 응답을 더한다. 설계서(T1-3 규칙 한 줄, T3-2 API, T3-5 시험)를 먼저 고친다.

알림

- 같은 파일: 상태 전환에 주인 확인을 넣느라 BidFSMService.java 를 고친다(작업본에 다른 창 수정이 있다). BidRequestRepository 는 고치지 않는다.
- 규칙 번호: T1-3 에 "입찰 건은 낸 회원과 관리자만" 규칙 한 줄이 필요하다. BIZ-050~059 는 CR-142 몫이라 번호를 받아야 한다.
- 마이그레이션은 없다.
