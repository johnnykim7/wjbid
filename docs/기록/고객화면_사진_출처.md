# 고객 화면 사진 출처

고객 포털(frontend/customer-portal/public/img/)에 둔 사진마다 출처, 작가, 이용 조건을 적는다. 사진을 더하거나 바꾸면 이 표에 줄을 더하고, 지운 사진은 지운 CR 을 적는다.

## 이용 조건 요약

- **미 정부 공공 저작물**: 미 연방 공무원이 직무로 찍은 사진은 저작권이 없다(17 U.S.C. 105). 상업 이용이 가능하다. 다만 미 국방부와 군이 우리 서비스를 보증하는 것처럼 보이게 쓰지 않는다. 부대 마크를 앞세운 사진을 고르지 않고, 사진 위나 옆에 보증으로 읽히는 문구를 두지 않는다.
- **Pexels 라이선스** (https://www.pexels.com/license/): 무료, 상업 이용 가능, 출처 표시 의무 없음. 사진을 그대로 되파는 것, 사진 속 사람이 상품이나 서비스를 보증하는 것처럼 쓰는 것, 사람을 나쁘게 그리는 것은 금지다.
- AI 로 만든 사진은 쓰지 않는다. 아래 사진은 모두 촬영일이 있는 실사진이다.
