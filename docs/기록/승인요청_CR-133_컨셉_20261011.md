# CR-133 첫 묶음 화면 컨셉 승인요청 (2026-10-11)

첫 묶음: 등록·컨설팅 8, 입찰 교실 4, 고객센터 속페이지 4 새 모양, 나머지 17개 항목별 안내(사용자 06:01 /전승).
컨셉: docs/CR-133_메뉴_속_화면_계획과_첫_묶음_구현.md 5절. 속페이지 틀(위치 줄, 왼쪽 묶음 메뉴, 오른쪽 본문)을 새로 두고 그 안에 서비스 안내, 입찰 교실, 항목별 안내, 고객센터를 넣는다.

| 순번 | 정할 것 | 선택지 |
|------|--------|--------|
| 1 | 화면 컨셉 | ①컨셉+목업(권장, 속페이지 틀이 새 모양이라 홈 시안 완성도로 그려 보고 정함) ②컨셉만 ③그냥 진행 |
| 2 | 공지사항 견본 6건(없는 기능 안내 포함) | ①모두 지우고 실제 공지만 둔다. 0건이면 "아직 공지가 없습니다"(권장) ②사실과 다른 2건만 지운다 |
| 3 | 제안서 자문 | ①서비스 후보 메모대로 법무 확인 전에는 항목별 안내로 두고, 확인 뒤 서비스 화면으로 연다(권장) ②"자문·검토" 로 서비스 화면을 내고 상담 신청만 받는다 |
| 4 | 안내 글 내용 | ①등록 절차는 공식 안내(SAM.gov, PIEE 등)를 근거로 쓰고, WJbid 가 하는 일과 비용은 서비스 후보 문구 안에서만 쓴다. 발주사 확인은 배포 뒤 받아 고친다(권장) ②발주사 확인 뒤 배포한다 |

알림

- 메뉴 정의(menu.ts)를 고친다: 12개 항목에 목적지를 넣고 17개는 항목별 안내로 보낸다. 공통 틀(components/layout/)은 고치지 않는다.
- 상담 신청 단추는 1:1 문의를 유형과 제목을 채운 채로 연다. CR-132 에 [계약]이 필요하다: 1:1 문의 화면이 주소의 유형 코드와 제목을 받아 채워 줄 것, 문의 유형 코드 목록에 서비스 상담 유형이 있을 것.
