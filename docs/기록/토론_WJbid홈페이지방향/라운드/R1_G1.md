# R1 - G1 (처음 온 입찰 희망자)

## 안

**새 안 C+: 짧은 시작 안내를 붙인 공통 검색형.**
첫 화면에 ‘주한미군 입찰’이라는 설명, 공고 검색창, 마감 전 공고 3건과 마감일을 놓는다. 검색어를 몰라도 목록부터 볼 수 있게 한다.
아래는 ‘실제 한글 분석 예시와 시작 순서 → 기지별 공고·낙찰 근거 → 무료 이용 범위·자주 묻는 질문·가입’ 순서로 구성한다.
로그인 전후에 검색과 공고 위치는 유지하고, 로그인 후에는 가입·로그인 자리를 관심 공고·내 계정으로 바꾼다. 세부 구성의 근거와 조건은 G1-1~G1-12에 적는다.

## 이 안을 버릴 조건

- **처음 온 사람이 공고를 보고도 시작하지 못하는 경우.** 같은 자료·글자 크기로 비교한 B 또는 D의 방문자 화면보다 C+에서 첫 행동을 고르는 데 오래 걸리고, 자기 회사와 관련된 공고를 찾거나 다음 준비를 이해하는 비율도 반복해서 낮으면 공통 검색형을 버린다. [추정] G1-1과 G1-6의 가설을 반증하는 조건이다.
- **회원의 실제 주업무가 공통 목록보다 개인 공고 관리인 경우.** 이용 기록과 과업 비교에서 관심 공고·저장 검색·마감 관리가 중심이며 C+의 바로가기만으로 업무 접근이 충분히 빨라지지 않으면 D를 선택한다. [추정] G1-7의 공통 화면 유지 판단이 바뀌는 조건이다.
- **현재 데이터로 첫 화면의 공고를 믿을 만하게 보여줄 수 없는 경우.** 마감 전 판별·중복 제거·갱신·조회 오류를 기존 기능 범위에서 해결할 수 없으면, 실공고 중심 안을 그대로 출시하지 않고 검증된 예시와 안내 중심으로 바꾼다. [추정] G1-4와 G1-12가 성립하지 않는 조건이다.
- **설명과 목록을 함께 두어도 가독성과 행동 명확성을 동시에 확보하지 못하는 경우.** 1440×900에서 제안한 글자 크기를 지키면 공고가 밀려나거나 첫 행동이 계속 분산된다면, 절충 구성을 고집하지 않고 소개와 업무 화면을 나눈다. [추정] G1-2와 G1-3의 설계 가설이 실패하는 조건이다.

## 모르는 것

- 처음 온 사람·재방문자·로그인 회원의 비율과 유입 목적. 로그인 상태가 안내 필요성과 얼마나 관련되는지.
- 실제 방문자가 입찰 용어와 영문 공고를 어느 정도 읽는지. 한글 분석이 없는 현재 공고 목록만으로 관심을 판단할 수 있는지.

- 마감 전 공고 13건의 개별 내용·제목 언어·공고 유형·기지 매핑과 홈 목록의 연동 가능 여부.

- 요금 소스의 기능·제한이 운영에 그대로 반영됐는지, 가입 후 첫 사용이 실제로 원활한지.
