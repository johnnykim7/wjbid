# R1 - C2 (매일 쓰는 회원과 운영)

## 안
새 안 E "공고판 포털". 안 A 의 포털 틀(머리 검색, 메뉴 띠, 오른쪽 상자)은 지키되 첫 화면의 주인을 공고 목록으로 바꾸고, 로그인하면 오른쪽 한 칸만 바뀐다.
- 첫 화면: 머리 한 줄(로고, 검색창, 메뉴 5~6개, 로그인, 무료로 시작). 왼쪽 넓은 칸에 "지금 마감 전 공고" 전체를 마감 순으로(줄마다 D-day, 기지, 한글 제목, 새 공고 표시, 한글 분석 있음 표시). 오른쪽 좁은 칸 하나는 로그인 전에는 한 줄 문구와 "무료로 시작" 버튼 하나와 시작 3단계, 로그인 후에는 내 관심 공고, 마감 임박, 진행 중 제안서, 알림 설정 상태와 그 화면으로 가는 길.
- 그 아래: 낙찰 공지와 기지별 숫자, 한글 분석 견본 하나, 자주 묻는 질문. 아이콘 10개 줄, 돌아가는 배너, 손으로 쓰는 공지 칸, 아직 화면이 없는 기능으로 가는 링크는 홈에서 뺀다.
- 홈의 숫자와 목록은 운영 DB 에서 자동으로 채우고 셈법 하나(공고번호 기준)로 맞춘다. 사람이 매일 손대야 하는 칸은 두지 않는다.

## 이 안을 버릴 조건
- 마감 전 공고를 홈에 올리려면 공고마다 사람이 승인하거나 번역해야 하고, 그것을 매일 해낼 수 없다고 드러나면 버린다. 목록이 자주 비는 홈은 B 나 C 의 숫자 중심보다 못하다.
- 접속 기록에서 홈을 거치는 로그인 회원이 거의 없다고(회원은 알림 메일에서 상세로 바로 간다) 드러나면, 회원 몫 칸의 값어치가 낮으니 처음 온 사람 쪽(B, D)으로 기운다.
- 마감 전 공고가 수십 건 이상으로 늘어 첫 화면 목록이 "전체" 가 못 되면, 검색과 거르기를 앞에 두는 C 로 옮긴다.
- 관심 공고, 저장한 검색, 알림 화면이 실제 데이터가 아니라 더미로 드러나면 오른쪽 회원 칸은 빼고 목록 중심만 남긴다.

- 운영 홈 공고 칸이 비어 있는 까닭. 노출 조건 때문인지 불러오기 실패 때문인지, 홈이 부르는 공고 목록이 무엇을 걸러 오는지
- 마감 전 13건에 한글 제목이 붙어 있는지. 6안 목록은 한글 제목을 달았지만 한글 공고문은 0건이다
- 관심 공고, 저장한 검색, 캘린더, 알림, 제안서 화면이 실제 데이터로 도는지(홈 공지사항은 더미로 확인됨)
- 홈 방문자 가운데 로그인 회원의 비율, 회원이 홈을 거치는지 알림 메일에서 바로 상세로 가는지
- 마감일별 합 14건과 마감 전 13건이 1건 다른 까닭(한 공고에 마감일이 둘인지)
- 2안의 47, 14 와 6안의 22, 8 이 같은 "10.10 기준" 인데 다른 까닭
- 공지사항을 올리고 고치는 관리자 기능이 있는지, 맡을 사람이 있는지
- 경쟁 사이트가 로그인한 회원에게 보여주는 첫 화면(쟁점지에서도 모르는 사실)
