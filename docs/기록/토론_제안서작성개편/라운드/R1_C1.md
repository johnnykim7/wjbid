# R1 - C1 (수주력과 사실 충실)

## 안
안 C 를 고친 새 안 C' 를 낸다. 문서를 꼴로 나누는 것은 C 와 같고, 넷을 바꾼다.
1. 증빙 묶음형(A-1 등록, A-2 수행 경험, A-5 핵심 인력, B 과거 실적)은 긴 서술을 버리고, 요구 줄마다 증빙 위치(파일, 쪽)와 충족, 미충족을 적는 대응표와 짧은 설명으로 낸다. 최소 단어 하한을 없앤다.
2. 스킬 1, 2단계는 이미 도는 공고 분석과 입찰 분석을 그대로 살리고, 입찰 분석이 찾은 서류 결함과 미충족 관문을 작성과 검증 입력으로 넘긴다. 3 ~ 7단계는 서술형 계획서(A-3 관리 계획, A-4 장비 계획)에만 넣고, 3단계 수주 전략과 7단계 리뷰는 평가 방식으로 깊이를 가른다(LPTA 는 관문 점검과 가격 전략, 최고 가치 절충은 03, 07 전부).
3. 가격은 서술 절을 버리고 공고 가격 항목으로 연차별 입찰 일정표와 산출 근거 틀(인상률, 인력, 장비 산출 칸)을 만든다. 단가는 고객이 넣는다. 정부 양식은 CR-189 그대로 둔다.
4. 순서: (1) CR-189 뒤 같은 건을 원재료 서류로 재시험해 기준선을 다시 잰다 (2) 관문 점검(CR-174 의 제1부 자동 검증과 Gold 를 떼어 앞당김), 입찰 분석 결함 전달, 증빙형 축소 (3) 가격 틀 (4) CR-171 평가 방식별 수주 전략과 승인 관문 (5) CR-172 절 기획(서술형만)과 영문 본문 (6) CR-173 의 도식, 장 표지, 워드 서식 (7) CR-174 나머지(7기준 평가, 모의 채점은 절충형) (8) CR-175 는 제안서 작성 밖이라 이번 개편에서 뺀다.

살릴 것: 공고 분석(매트릭스, 공고 사실), 입찰 분석, 장 절 블록 저장과 절 트리, 문장 단위 충실성 검증, CR-189 의 공고 사실, 가격 항목, 정부 양식, 문서 구성(CR-180). 버릴 것: 증빙형 장의 최소 단어와 긴 서술, 가격 서술 절, 한국어 초안 지시, 요구 미대응을 판정에서 빼는 규칙.

## 이 안을 버릴 조건
- 원재료 서류로 다시 돌린 재시험에서 지금 흐름(CR-189 뒤)만으로 7절 모두 검증 합격, 근거 없는 문장 0 이고 관문 미충족도 드러나면, 꼴 분리 없이 안 A 로 충분하다.
- 이 건의 평가 기록이나 다른 낙찰 건에서 증빙형 장의 서술 분량이 합격, 불합격을 가른 사례가 나오면 증빙형 축소를 버린다.
- 최고 가치 절충 공고의 낙찰 제출본이 모든 장을 서술형으로 낸 꼴이면, 절충형은 안 B 쪽으로 간다.
- 가격 엑셀 꼴이 공고마다 달라 공통 틀을 세울 수 없으면, 가격은 CR-189 의 가격 표에서 멈춘다.
