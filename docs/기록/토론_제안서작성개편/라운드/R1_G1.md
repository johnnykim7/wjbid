# R1 - G1 (수주력과 사실 충실)

## 안

**안 D: 공통 7단계와 요구사항별 작성 방식의 결합.** 스킬 7단계를 전체 작성의 뼈대로 삼되, 이미 운영하는 공고 분석·입찰 분석을 1·2단계로 연결하고 중복 실행하지 않는다.
3단계 전략 승인, 4단계 목차·제출물 설계, 5단계 절 기획서를 거친 뒤, 6단계 안에서 서술·증빙·가격·정부 양식에 맞는 방식으로 작성한다. 한 절에도 여러 방식을 함께 쓸 수 있다.
7단계는 절별 사실 검증에 더해 전체 요구 대응과 최종 제출물 검사를 수행한다. 장·절·블록 저장과 관리자 화면은 살리고, 모든 절에 긴 설명을 요구하는 규칙과 사실 검증 PASS를 제출 가능으로 받아들이는 방식은 버린다.
스킬 파일은 유지하고 단계 연결·입출력·승인·재실행 규칙을 서버와 `docs/workflows/`에 둔다. 아래 설계와 효과 전망은 자료에서 도출한 제안이며, 개선 효과가 실측됐다는 뜻은 아니다.
