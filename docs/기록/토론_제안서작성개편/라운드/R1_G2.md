# R1 - G2 (구현과 운영)

## 안

**안 C를 보완한 새 안: 공통 7단계와 산출물 종류별 실행을 결합한다.**
공고 분석·입찰 분석을 1·2단계로 재사용하고, 승인된 전략 → 목차 → 절 기획 → 작성 → 전체 리뷰를 서버가 잇는다.
작성은 서술, 증빙, 가격, 정부 양식으로 나누되, 한 절에 여러 종류가 섞일 수 있게 한다. 모든 산출물은 공통 요구사항·출처·버전·완료 상태로 추적한다.
CR-189 재시험과 제출 검사부터 시작해 CR-171·172, CR-173의 제출 필수 기능, CR-174 전체 리뷰, 표현 고도화, CR-175 순서로 나눠 들인다.
