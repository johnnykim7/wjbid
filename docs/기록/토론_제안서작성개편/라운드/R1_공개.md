# R1 - C1 (수주력과 사실 충실)

## 안
안 C 를 고친 새 안 C' 를 낸다. 문서를 꼴로 나누는 것은 C 와 같고, 넷을 바꾼다.
1. 증빙 묶음형(A-1 등록, A-2 수행 경험, A-5 핵심 인력, B 과거 실적)은 긴 서술을 버리고, 요구 줄마다 증빙 위치(파일, 쪽)와 충족, 미충족을 적는 대응표와 짧은 설명으로 낸다. 최소 단어 하한을 없앤다.
2. 스킬 1, 2단계는 이미 도는 공고 분석과 입찰 분석을 그대로 살리고, 입찰 분석이 찾은 서류 결함과 미충족 관문을 작성과 검증 입력으로 넘긴다. 3 ~ 7단계는 서술형 계획서(A-3 관리 계획, A-4 장비 계획)에만 넣고, 3단계 수주 전략과 7단계 리뷰는 평가 방식으로 깊이를 가른다(LPTA 는 관문 점검과 가격 전략, 최고 가치 절충은 03, 07 전부).
3. 가격은 서술 절을 버리고 공고 가격 항목으로 연차별 입찰 일정표와 산출 근거 틀(인상률, 인력, 장비 산출 칸)을 만든다. 단가는 고객이 넣는다. 정부 양식은 CR-189 그대로 둔다.
4. 순서: (1) CR-189 뒤 같은 건을 원재료 서류로 재시험해 기준선을 다시 잰다 (2) 관문 점검(CR-174 의 제1부 자동 검증과 Gold 를 떼어 앞당김), 입찰 분석 결함 전달, 증빙형 축소 (3) 가격 틀 (4) CR-171 평가 방식별 수주 전략과 승인 관문 (5) CR-172 절 기획(서술형만)과 영문 본문 (6) CR-173 의 도식, 장 표지, 워드 서식 (7) CR-174 나머지(7기준 평가, 모의 채점은 절충형) (8) CR-175 는 제안서 작성 밖이라 이번 개편에서 뺀다.

살릴 것: 공고 분석(매트릭스, 공고 사실), 입찰 분석, 장 절 블록 저장과 절 트리, 문장 단위 충실성 검증, CR-189 의 공고 사실, 가격 항목, 정부 양식, 문서 구성(CR-180). 버릴 것: 증빙형 장의 최소 단어와 긴 서술, 가격 서술 절, 한국어 초안 지시, 요구 미대응을 판정에서 빼는 규칙.

## 이 안을 버릴 조건
- CR-189 재시험에서 같은 건의 불합격 절과 근거 없는 문장이 모두 0 이면 기획서를 맨 앞에 둘 이유(C2-3, C2-4)가 약해진다. 그때는 작성 꼴과 내보내기(C2-6, C2-7)를 첫 자리로 올린다.
- 공고 사실과 고객 서류 사실에 기획서가 가리킬 안정된 키가 없어 서버가 근거 지정을 대조할 수 없으면 C2-3 의 핵심이 무너진다. 그때는 근거 대조를 검증 단계에만 두는 쪽으로 물러난다.
- 스킬 4 ~ 6단계를 한 에이전트 호출 안에서 파일로 이어 가는 꼴(안 B 쪽)이 같은 건에서 시간과 불합격 수 둘 다 낫다는 결과가 나오면 이 안을 버린다.
- 관리자가 AI 판정과 다른 조건으로 Go 하는 일이 잦거나 No-Go 가 대부분이면 전략을 입찰 분석 끝에 두는 C2-8 을 버리고 Go 뒤 별도 관문으로 옮긴다.
- 최고 가치 절충 낙찰 건을 구해 돌렸을 때 전략 유무가 결과를 크게 가르면 전략(CR-171)을 순서 맨 앞으로 당긴다.

# R1 - G1 (수주력과 사실 충실)

## 안

**안 D: 공통 7단계와 요구사항별 작성 방식의 결합.** 스킬 7단계를 전체 작성의 뼈대로 삼되, 이미 운영하는 공고 분석·입찰 분석을 1·2단계로 연결하고 중복 실행하지 않는다.
3단계 전략 승인, 4단계 목차·제출물 설계, 5단계 절 기획서를 거친 뒤, 6단계 안에서 서술·증빙·가격·정부 양식에 맞는 방식으로 작성한다. 한 절에도 여러 방식을 함께 쓸 수 있다.
7단계는 절별 사실 검증에 더해 전체 요구 대응과 최종 제출물 검사를 수행한다. 장·절·블록 저장과 관리자 화면은 살리고, 모든 절에 긴 설명을 요구하는 규칙과 사실 검증 PASS를 제출 가능으로 받아들이는 방식은 버린다.
스킬 파일은 유지하고 단계 연결·입출력·승인·재실행 규칙을 서버와 `docs/workflows/`에 둔다. 아래 설계와 효과 전망은 자료에서 도출한 제안이며, 개선 효과가 실측됐다는 뜻은 아니다.
