## 정책 목록

### POL-001 | 공고 수집 주기
- **적용 모듈**: B. 공고 수집
- **정책 설명**: SAM.gov 자동 수집 스케줄. 기본값: 1일 4회 (06:00, 12:00, 18:00, 23:00 KST). cron 표현식으로 관리.
- **변경 가능 여부**: 가능 (application.yml 또는 DB 설정)
- **관련 기능 ID**: BID-OPP-001

### POL-002 | 수집 키워드 목록
- **적용 모듈**: B. 공고 수집
- **정책 설명**: SAM.gov 검색에 사용할 키워드 목록. 기본값: "411th csb", Camp Casey, Osan AB, Humphreys 등. 관리자가 추가/삭제 가능.
- **변경 가능 여부**: 가능 (DB 또는 설정)
- **관련 기능 ID**: BID-OPP-001

### POL-003 | 수집 알림 발송 조건
- **적용 모듈**: B. 공고 수집 / L. 알림
- **정책 설명**: 신규 공고 수집 시 알림 발송 여부. 기본값: 신규 공고 1건 이상일 때만 발송. 0건이면 미발송.
- **변경 가능 여부**: 가능 (발송 임계값 조정 가능)
- **관련 기능 ID**: BID-OPP-004

### POL-004 | 알림 수신자 목록
- **적용 모듈**: L. 알림
- **정책 설명**: 이메일 알림 수신자 목록. 기본값: ADMIN 역할 전원. 개별 수신 설정 가능.
- **변경 가능 여부**: 가능 (DB 관리)
- **관련 기능 ID**: BID-OPP-004, BID-DOC-002

### POL-005 | 자동 생성 문서 타입
- **적용 모듈**: E. 문서 생성
- **정책 설명**: AI 제안서 자동 생성 시 기본 생성할 문서 타입. 기본값: COVER_LETTER, TECHNICAL_PROPOSAL. 관리자가 공고별로 조정 가능.
- **변경 가능 여부**: 가능
- **관련 기능 ID**: BID-DOC-001

### POL-006 | FSM 전이 테이블
- **적용 모듈**: I. 상태 관리
- **정책 설명**: BidRequest의 허용 상태 전이 매트릭스. 화이트리스트 방식. 전이 추가/제거는 설계 변경 필요.

## 정책 vs 비즈니스 규칙 구분 기준

- **비즈니스 규칙 (T1-3)**: 변하지 않는 핵심 규칙. 예) 'FSM 화이트리스트', '문서 버전 불변성'
- **정책 (T1-4)**: 변경 가능한 규칙. 예) '수집 주기=4회/일', '마감 알림=D-7,D-3,D-1'

구현 시 차이: 비즈니스 규칙은 코드에 고정. 정책은 설정/DB로 관리하여 변경 가능하게.
