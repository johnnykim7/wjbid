## 원문

### 공고 수집/분석 강화
1. 공고 자동 분류/스코어링 — AI가 "낙찰 가능성" 평가. 과거 입찰 이력, 회사 역량 기반
2. 마감일 임박 알림 — D-7, D-3, D-1 자동 이메일 알림
3. 경쟁사 분석 — SAM.gov 과거 낙찰 이력 수집, 경쟁사 정보 정리

### 문서 관련
4. AI 문서 품질 검토 — 생성된 제안서를 AI가 재검토, "누락된 항목", "표현 개선 제안" 피드백
5. 과거 제안서 학습 — 성공한 제안서를 RAG로 학습, 새 제안서 작성 시 참고 (Aimbase RAG 활용)
6. 다국어 지원 — 한국어 입력 → 영문 제안서 자동 변환

### 고객/워크플로우
7. 고객 포털 진행 현황 추적 — 입찰 건의 현재 단계를 실시간 진행바/타임라인으로 표시
8. 고객-관리자 메모/커뮤니케이션 — 입찰 건별 코멘트 기능
9. 입찰 결과 기록 — 제출 후 낙찰/탈락 결과 기록, 성공률 분석

### 운영/관리
10. 감사 로그 — 문서 수정, 상태 변경 등 전체 이력 추적
11. 정기 리포트 — 주간/월간 입찰 현황 요약 이메일 자동 발송

### 가격 정책/과금
12. 서비스 요금 체계 — 가격표 페이지 (건별/구독/성공보수)
13. 견적 시뮬레이터 — 공고별 자동 견적
14. 크레딧 시스템 — 선불 충전 → 서비스 이용 시 차감
15. 서비스 단계별 선택 — 모니터링만 / 분석+정리 / AI 초안 / 풀패키지
16. 무료 체험 — 첫 1건 무료/할인

### 고객 결제/정산
17. 결제 연동 — 카드/계좌이체 (Toss/Stripe)
18. 이용 내역/영수증 — 비용, 결제 내역, 세금계산서
19. 자동 청구 — 구독제 월별 자동 결제

### 고객 가치 제안
20. 예상 절감 효과 표시 — 직접 준비 vs 서비스 이용 비교
21. 성공 사례/통계 — N건 대행, 낙찰률 X% 표시
22. 공고별 난이도/경쟁률 표시 — AI 분석 결과 제공

### 부가서비스
23. 입찰 트렌드 리포트 — 월간/분기별 USFK 입찰 트렌드 분석 (유료 구독)
24. 맞춤 공고 알림 — 고객 업종/역량 기반 AI 매칭 필터링
25. 경쟁사 낙찰 정보 모니터링 — 특정 업체/분야 낙찰 현황 추적
26. 제안서 컨설팅/코칭 — AI가 약점/보강점 피드백
27. 입찰 자격 진단 — 회사 정보 기반 자격 여부 AI 사전 진단
28. 필수 인증/서류 가이드 — SAM 등록, CAGE Code, DUNS 등 취득 절차 안내 + 체크리스트
29. 전문가 리뷰 — AI + 실제 전문가 최종 검토 (프리미엄)
30. 번역/현지화 — 한영 번역 + 네이티브 감수
31. 문서 보관함 — 고객별 서류 클라우드 보관, 재활용
32. 템플릿 마켓 — 분야별 우수 제안서 템플릿 구매/다운로드
33. 파트너 매칭 — 컨소시엄 매칭, 중개 수수료
34. 하도급 연결 — 낙찰 후 이행 위한 하도급 업체 연결
35. 계약 이행 관리 — 낙찰 후 일정/납품/보고서 관리 + 캘린더 알림
36. 실적 증명서 관리 — 완료 계약 실적 증명서 자동 관리, 다음 입찰 재활용

### MVP / 이후 확장 구분 (합의됨)

**MVP (1차 오픈):**
- 핵심 흐름: 공고 수집 → 열람 → 입찰 신청 → AI 제안서 생성 → 관리자 편집
- 이메일 알림 (수집/문서 완료)
- 첨부문서 자동 획득
- 문서 템플릿 관리
- MCP 서버 (Aimbase 연동)
- 서비스 요금 안내 페이지 (결제 연동 없이, 가격표만)
- 입찰 자격 진단 (간단 버전)

**이후 확장:**
- 결제 연동, 크레딧 시스템
- 트렌드 리포트, 경쟁사 모니터링
- 파트너 매칭, 전문가 리뷰
- 문서 보관함, 템플릿 마켓
- 성공 사례/통계, 견적 시뮬레이터
- 계약 이행 관리
- 번역/현지화
- 고객-관리자 커뮤니케이션
- 정기 리포트
