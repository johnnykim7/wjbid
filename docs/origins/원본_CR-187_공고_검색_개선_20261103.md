# 원본: CR-187 공고 검색 개선 (2026-11-03)

## 발주사 장표 「우진비드 개선사항」 10장 (11/2 올라옴)

Q.공고명_ 키워드로 검색이 잘 안됩니다.
(예. 부산.험프리스. 차량 정비등….)

## 사용자에게 보인 설계안 (11/3)

검색 설계안 [규모] 중 (승인을 받은 뒤 설계서부터 고칩니다)

[사실·확인함] 지금 검색은 세 가지 때문에 잘 안 걸립니다.
- 마감 전 공고 11건 안에서만 찾습니다.
- 한글로 친 기지 이름은 한글 제목에 그 글자가 그대로 있어야만 걸립니다.
- 띄어쓰기까지 똑같아야 걸립니다.

검색 화면의 발주처 칸과 상태 칸은 골라도 결과가 바뀌지 않습니다.

고칠 것:
1. 검색어를 넣으면 마감이 지난 공고와 낙찰 공지까지 찾습니다. 마감 전 공고를 맨 위에 두고, 화면 제목은 "검색 결과"로 바꿉니다.
2. 관리자 기지 관리에 넣은 한글 이름과 지역으로도 찾습니다. 예를 들어 "평택"을 치면 험프리스 공고와 오산 공고가 나옵니다.
3. 띄어쓰기는 무시합니다. "차량정비"와 "차량 정비"가 같은 결과를 냅니다.
4. 골라도 아무 일이 없는 발주처 칸과 상태 칸은 뺍니다.
5. 추천 검색어는 지금 화면에 고정된 5개 대신, 공고가 많은 기지 이름 순으로 자동으로 채웁니다. "시설 유지관리"처럼 결과가 0건인 말은 빠집니다.

상용 자료로 미리 돌려 본 결과:

| 검색어 | 지금 | 바꾼 뒤 |
|---|---|---|
| 부산 | 0건 | 5건 |
| 험프리스 | 1건 | 42건 |
| 평택 | 0건 | 61건 |
| 차량정비 | 0건 | 3건 |

정하실 것: 검색 결과에 낙찰 공지를 넣을지입니다.
1. 이대로 낙찰 공지까지 넣어 진행합니다 (권장)
2. 낙찰 공지는 빼고 입찰 공고만 찾습니다. 이 경우 부산은 1건, 험프리스는 34건입니다.
