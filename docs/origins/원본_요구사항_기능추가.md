## 원문

[서비스 개요]
1) 입찰 사이트 주기적 조회하여, 입찰 정보 우리 사이트에 표시
2) 입찰 정보를 가져옸을 경우 관리자에게 이메일 또는 문자로 알림. (현실적으로는 이메일)
3) 입찰사이트로부터 첨부문서 획득, (첨부가 있는 경우)
   --> 첨부문서가 링크 형태로되어있는 경우 그 링크를 따라가서 다운로드하여 문서 가져옴 (만약 가져올수 없으면 링크 제공)
4) 사용자 입장에서는 입찰정보를 클릭하여 입찰 참여의사를 밝히면 필요한 첨부문서를 전부 등록해야함. 필요한 첨부문서는 입찰사이트에서 안내하고 있음.
  입찰사이트의 공고를 가져온후. 필요 문서에 대한 부분을 따로 보기좋게 정리해서 보여줘야함.
5) 사용자가 필요문서를 입력하여 신청하면, AI를통하여 관리자가 사전에 등록한 문서 포맷에 따라 제안서를 작성해줌..
6) 5)번의 문서포맷은 관리자가 사전에 등록.. 상황에 따라 여러 포맷을 등록할수 있어야함.
7) ai를 통해 문서가 완성이 되면.. 관리자에게 이메일을 보내 완성되었다는것을 알림.
8) 관리자가 해당 문서를 보고 후처리로 수정작업을 할수 있는 ui를 제공해야함.

[추가 컨텍스트 — 대화에서 확인된 사항]
- AI 연동은 Aimbase(조직 내 LLM 오케스트레이션 플랫폼) 활용. 기존 자체 LLM Platform 연동 대체.
- 이 프로젝트(Bidding Platform)는 MCP 서버가 되어 Aimbase가 도구(tool)를 호출하는 구조.
- 사용자 모델 단순화: 관리자 중심 운영. 고객은 간단한 접수(입찰 참여 의사 + 필요 문서 제출)만 하고, 관리자가 대행.
- 기술 스택은 현재 유지 (Java 17 + Spring Boot 3.2 + React 19)
- 입찰 사이트는 SAM.gov만 대상
- FlowGuard 검증 비대상
- 더 많은 아이디어는 대화를 통해 진행 예정
