## 원문

### 프로젝트 개요

SAM.gov 입찰 대행 플랫폼. 미군(USFK) 조달 입찰을 자동화하는 B2B 서비스.
- SAM.gov에서 공고 자동 수집 → AI로 요구사항 추출 → 입찰 문서 자동 생성 → 컴플라이언스 검증 → 제출 관리
- 대상 고객: 미군 정부 계약에 입찰하는 한국 기업

### 기술 스택

- BE: Java 17 + Spring Boot 3.2 + MariaDB 11.2 + Redis 7.2 + MinIO
- FE: React 19 + Vite 7 + TypeScript 5 (customer-portal 5173, admin-console 5174)
- AI: OpenAI GPT-4 (외부 LLM Platform 연동, localhost:9000)
- Infra: Docker Compose (MariaDB, Redis, MinIO, Prometheus, Grafana)
- 보안: JWT (HS256, Access 15min, Refresh 7day), Spring Security, RBAC

### 기존 구현 기능 목록

#### 1. 인증/인가
- 이메일 회원가입 (회사명, 역할 포함)
- JWT 기반 로그인/로그아웃
- Refresh Token 갱신
- RBAC 6개 역할: ADMIN, ANALYST, WRITER, REVIEWER, SUBMITTER, MEMBER

#### 2. 공고 수집 (SAM.gov)
- 스케줄 기반 자동 수집: 4회/일 (06:00, 12:00, 18:00, 23:00 KST)
- 키워드: "411th csb", Camp Casey, Osan AB, Humphreys 등
- 증분 동기화: latest_posted_date - 1일 또는 fallback 7일
- 콘텐츠 해시 기반 중복 검출
- Raw JSON 원본 보존 (감사 추적)
- 수동 수집 트리거 (관리자)
- 수동 공고 입력 (관리자)

#### 3. 공고 조회/검색
- 페이징/필터/검색 지원 목록
- 공고 상세 (요구사항 포함)
- 북마크 (즐겨찾기)

#### 4. 입찰 요청 관리 (BidRequest)
- 입찰 요청 생성 (공고 선택 → CREATED 상태)
- 12단계 FSM 상태 관리:
  CREATED → WAITING_FOR_CLIENT_DOCS → CLIENT_DOCS_RECEIVED
  → REQUIREMENT_ANALYSIS → DOCUMENT_DRAFTING → INTERNAL_REVIEW
  → CLIENT_CONFIRMATION → READY_FOR_SUBMISSION → SUBMITTING
  → SUBMITTED / SUBMIT_FAILED → CLOSED
- 상태 전이 검증 (화이트리스트 방식)
- 상태 이력 추적 (JSON)
- 다음 가능 상태 조회

#### 5. 요구사항 분석 (AI)
- REQUIREMENT_ANALYSIS 상태 진입 시 자동 트리거
- LLM Platform workflow 호출 (`requirement-extraction`)
- 구조화된 요구사항 추출: category, title, description, is_blocker
- BLOCKER 시스템: 미충족 시 제출 차단

#### 6. 문서 생성 (AI)
- DOCUMENT_DRAFTING 상태 진입 시 자동 트리거
- 자동 생성 타입: COVER_LETTER, TECHNICAL_PROPOSAL
- LLM Platform workflow 호출 (`bid-document-generation`)
- TipTap JSON 형식 (Rich text editor)
- 버전 관리: 모든 저장 시 새 immutable 버전 생성

#### 7. 문서 관리
- 문서 타입: COVER_LETTER, TECHNICAL_PROPOSAL, PAST_PERFORMANCE, COMPANY_PROFILE, COMPLIANCE_MATRIX, PRICING_SUMMARY, OTHER
- 문서 상태: DRAFT → LOCKED → ARCHIVED
- 문서 잠금 (제출 시 LOCKED, 증거 보존)
- PDF 내보내기
- 버전 이력 조회

#### 8. 컴플라이언스 검증
- 요구사항 ↔ 문서 섹션 매핑 (fulfillment map)
- 충족 타입: DOCUMENT_SECTION, ATTACHMENT, MISSING
- 충족 상태: PENDING → FULFILLED / MISSING
- BLOCKER 요구사항 미충족 시 제출 차단

#### 9. 제출 관리
- 전자서명 (BidAuthorization)
- 제출 실행
- 실패 시 재시도

#### 10. 관리자 기능
- 회원 관리 (목록)
- 수집 통계
- 문서 템플릿 관리
- 수동 수집 트리거

#### 11. MCP Tool (Claude Code 연동)
- OpportunityMcpTool: 공고 조회/생성
- RequirementMcpTool: 요구사항 추출/관리
- DocumentMcpTool: 문서 CRUD
- DocumentTemplateMcpTool: 템플릿 관리

### 데이터 모델

| 테이블 | 용도 |
|--------|------|
| members | 사용자/회사 (email, company_name, role, subscription_status) |
| opportunities | SAM.gov 공고 (notice_id, title, posted_date, response_deadline, raw_json) |
| opportunity_requirement_items | 추출된 요구사항 (category, title, is_blocker, requirement_json) |
| bid_requests | 입찰 워크플로우 (member_id, opportunity_id, state, state_history) |
| bid_documents | 문서 컨테이너 (document_type, status, current_version_no) |
| bid_document_versions | 불변 버전 (content_json, edited_by, edited_at) |
| requirement_fulfillment_maps | 컴플라이언스 매트릭스 |
| bid_authorizations | 전자서명 기록 |
| bookmarks | 공고 즐겨찾기 |

### 외부 연동

- SAM.gov API: `https://api.sam.gov/opportunities/v2/search` (API Key 인증)
- LLM Platform: HTTP 폴링 방식 (2초 간격, 최대 90회 = 3분 타임아웃)
- MinIO (S3): 문서 저장, PDF, 첨부파일
- Redis: 캐시, 세션 저장, 작업 큐
