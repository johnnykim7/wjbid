# 02. Bid / No-Bid 결정

**역할**: "이길 수 있는가? 이겨도 되는가?"를 다각도로 정량 평가하고 결정 조언을 낸다.
**입력**: 1단계 산출물 (없으면 사용자 보유 정보로 대체 가능 — 단, 정확도 한계 고지)
**산출물**: `2-decision/bid-decision.md`

## 축 1. Pwin 스코어카드 (7팩터)

자사와 주요 경쟁사 각각에 대해 동일 팩터로 채점(1~5점)하고 가중 합산한다.

| 팩터 | 가중치 | 평가 기준 |
|---|---|---|
| 고객 관계 | 15% | 접촉 이력, 신뢰도, 과거 수행 만족도 |
| 솔루션 적합도 | 20% | 요구사항 대응률(매트릭스 기준), 기술 우위 |
| 경쟁 환경 | 15% | 경쟁사 수, BCC 상대 위치, 내정 징후 반영 |
| 가격 경쟁력 | 15% | 예가 대비 원가 구조, 가격 전략 여지 |
| 과거 실적 | 15% | 유사 레퍼런스의 양과 질 |
| 참여 인력 | 10% | 핵심 인력 자격·경험·가용성 |
| 환경 요인 | 10% | 정책 부합, 지역·제도 요건 |

- 각 점수에 **근거를 반드시 병기**한다 (근거 없는 점수 금지)
- 민감도 분석: "어느 팩터를 1점 올리면 Pwin이 가장 크게 오르는가" → 3단계 전략의 우선 투자처
- 판단선: 70%+ Strong Go / 50~70% 조건부 Go / 30~50% Weak / 30% 미만 No-Go

## 축 2. 자격 검증

1단계 자격 체크리스트를 인계받아 미충족·조건부 항목의 해결 방안을 확정한다
(컨소시엄, 협력사, 서류 보완). **해결 불가 항목이 하나라도 있으면 즉시 No-Bid 플래그.**

## 축 3. 수익성

- Bottom-up: 인건비(등급×MM) + 직접경비 + 간접비 + 이윤
- Top-down 검증: 유사 사업 수익률 벤치마크
- 낙찰률 시나리오: 90% / 85% / 80%별 이익률
- Price Floor(최소 수용가) 산정, 숨은 비용(하자보증, 무상 유지보수, 이행보증) 반영

## 축 4. 리스크

재무(지급 지연, 지체상금) / 기술(난이도, 일정, 인력 이탈) / 계약(불리 조항, IP, 하자 책임)을
확률×영향도(H/M/L) 매트릭스로 정리. H×H 항목은 결정 조언에 반드시 반영.

## 객관적 강약점 도출 (서술 금지, 표에서 도출)

강약점은 "우리 생각"이 아니라 **BCC 점수 격차에서 기계적으로 도출**한다:
- 자사 점수 − 경쟁사 최고점 ≥ +1 → 강점 (Discriminator 후보)
- 자사 점수 − 경쟁사 최고점 ≤ −1 → 약점 (극복 대상)
- 격차가 크고 배점이 높은 항목 = 승부처

## 결정 조언 (3단 출력)

| 판정 | 내용 |
|---|---|
| **Strong Go** | 즉시 진행. 승부처와 우선 투자 팩터 명시 |
| **조건부 Go** | 진행하되 조건 명시 (예: "○○사 컨소시엄 확보 시", "PM급 인력 △△ 투입 확정 시"). **이 조건들은 3단계 수행전략의 필수 입력이 된다** |
| **No-Go** | 사유 명시. 단, 관계 구축·정보 획득 목적의 전략적 참여 옵션이 있으면 별도 언급 |

## 산출물 구조

```markdown
# Bid/No-Bid 결정 보고서 — {사업명}
## 1. Pwin 스코어카드 (자사 vs 경쟁사, 근거 포함) + 민감도 분석
## 2. 자격 검증 결과 (미충족 해결 방안)
## 3. 수익성 시뮬레이션 (시나리오별)
## 4. 리스크 매트릭스
## 5. 객관적 강약점 (BCC 격차 기반)
## 6. 최종 판정: Strong Go / 조건부 Go / No-Go + 조언
```

**HITL 게이트**: 이 결정은 반드시 사용자 승인을 받고 3단계로 진행한다.
