## 3. 고칠 방향

- 수집 때 번역 실행에서 번역은 저장 단위 밖에서 받고, 받은 뒤 짧은 저장 단위에서 공고를 다시 읽어 한글 제목이 비어 있을 때만 넣는다.
- 번역 10~20초 동안 DB 연결을 잡지 않는다.
- 저장 직전에 다시 읽으므로 같은 때 수집이 넣는 낙찰 정보(CR-136)를 옛 값으로 덮지 않는다. 엔티티는 바뀐 칸만 쓰지 않고 모든 칸을 다시 쓰므로, 번역 시작 때 읽은 공고를 그대로 저장하면 그 사이 들어온 값이 지워진다.
- 유형 한글 이름이 비어 있을 때 채우는 것도 같은 저장 단위에 넣는다(지금은 이것도 버려진다).
- 수집 코드(OpportunityCollectorService)는 고치지 않는다. CR-136 과 겹치지 않는다.
