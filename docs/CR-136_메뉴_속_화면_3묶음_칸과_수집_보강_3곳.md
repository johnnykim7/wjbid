- SAM 검색 주소: 코드에 박혀 있던 주소를 이미 있던 설정 app.sam-gov.api-url 에서 읽게 고쳤다. 로컬 확인에서 가짜 SAM 으로 돌리려면 필요했고, 운영 값은 같다.
- 다시 받기의 낙찰 공지 유형은 SAM 검색 조건 ptype=a 로 고른다. SAM 이 이 조건을 무시해도 받은 것 중 낙찰 공지만 다룬다.
- 금액 숫자 칸(award_amount_usd)은 V44 가 기존 금액 문자열에서 채우고, 그 뒤로는 수집이 채운다.

## 8. 다른 창에 알릴 것

- 2묶음(CR-135) 최근 낙찰 화면의 자료 기준 문구 "낙찰 업체 이름은 아직 모으지 않습니다" 는 이 CR 배포 뒤 맞지 않는다. 문구를 고치는 것은 2묶음 창 몫이라 컨타에 알린다.
- [계약] 2묶음에서 받음(10/11 07:50): 최근 낙찰 응답의 `awardeeKnownCount`(요약)와 `awardeeName`(줄)을 지금은 0 과 null 로 낸다. 이 CR 은 업체 이름 칸을 더할 때 이 두 값만 채운다. 화면 문구는 2묶음 화면이 값으로 바꾸므로 손대지 않는다.
- 알림 서버에 만료 메일 틀(BID_DOC_EXPIRY)을 새로 만드는 일은 알림 서버 레포 몫이라 컨타 경유로 요청한다. 원본 [templates/mail/BID_DOC_EXPIRY.json](templates/mail/BID_DOC_EXPIRY.json). 값: customerName, documentName, documentKind, expiresOn(YYYY-MM-DD), daysRemaining, expiryUrl(설정 app.customer-portal-url + /documents/expiry).
