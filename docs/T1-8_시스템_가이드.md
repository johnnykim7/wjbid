# SAM.gov Bidding Agency Platform 시스템 가이드 (비개발자용)

> 설계 버전: 1.0 | 최종 수정: 2026-03-19 | 관련 CR: -

> 단계: 1. Requirements 완료 시 | 이해관계자 리뷰 및 피드백 수집용

---

## 1. 시스템 한줄 소개

> 이 시스템은 **미군(USFK) 정부 조달 입찰에 참여하려는 한국 기업**을 위한 **AI 기반 입찰 대행 서비스**입니다.
>
> SAM.gov에 올라오는 입찰 공고를 자동으로 수집하고, AI가 제안서를 작성해주며, 관리자가 검토 후 최종 제출하는 전 과정을 지원합니다.

---

## 2. 전체 업무 흐름

```
[시스템이 SAM.gov에서 입찰 공고를 자동으로 가져온다]
        ↓
[새 공고가 있으면 관리자에게 이메일로 알려준다]
        ↓
[고객이 우리 사이트에서 공고 목록을 보고 관심 공고를 확인한다]
        ↓
[고객이 "이 입찰에 참여하겠다"고 신청한다]
        ↓
[시스템이 "이 입찰에 필요한 서류 목록"을 보여준다]
        ↓
[고객이 필요한 서류를 전부 올린다]
        ↓
[AI가 관리자가 미리 등록해둔 양식에 따라 제안서를 자동으로 작성한다]
        ↓
[제안서가 완성되면 관리자에게 이메일로 알려준다]
        ↓
[관리자가 제안서를 검토하고 필요하면 수정한다]
        ↓
[관리자가 최종 확정하고 입찰을 제출한다]
```

---

## 3. 주요 개념 설명

| 개념 | 설명 | 예시 |
|------|------|------|
| 공고 | SAM.gov에 올라오는 미군 조달 입찰 건 | "Camp Humphreys 시설 유지보수" |
| 입찰 신청 | 고객이 특정 공고에 참여하겠다고 요청하는 것 | 공고 상세에서 "입찰 참여" 클릭 |
| 필요 서류 | 입찰에 제출해야 하는 문서 목록 | 사업자등록증, 경력증명서, 인증서 등 |
| 제안서 | AI가 자동으로 작성하는 입찰 제출용 문서 | 커버레터, 기술제안서 등 |
| 문서 양식(템플릿) | 관리자가 미리 등록해둔 제안서 작성 형식 | "기술제안서 양식 A", "커버레터 양식" |
| 서비스 레벨 | 고객이 선택하는 대행 서비스 범위 | 모니터링만 / 분석+정리 / AI 제안서 / 풀패키지 |
| BLOCKER | 반드시 충족해야 하는 필수 요구사항 | 이것이 빠지면 입찰 자체가 불가능 |

## 4. 입찰 진행 흐름도 (상태 변화)

```
  신청 접수
     │
     ▼
  서류 안내 ──── 고객에게 "이런 서류가 필요합니다" 안내
     │
     ▼
  서류 접수 완료 ── 고객이 필요 서류를 전부 올림
     │
     ▼
  AI 분석 중 ──── AI가 공고 요구사항을 분석
     │
     ▼
  제안서 작성 중 ── AI가 양식에 맞춰 제안서 작성
     │
     ▼
  관리자 검토 ──── 관리자가 제안서를 보고 수정 가능
     │                    (다시 작성 필요하면 → "제안서 작성 중"으로 돌아감)
     ▼
  최종 확정 ────── 문서 잠금, 더 이상 수정 불가
     │                    (수정이 필요하면 → "관리자 검토"로 돌아감)
     ▼
  제출 완료 ────── 끝!
```

**취소 가능 시점**:
- "서류 접수 완료" 이전까지는 언제든 취소 가능
- 이후에는 관리자만 종료 처리 가능

**주의사항**:
- 입찰 마감이 다가오면 D-7, D-3, D-1에 자동으로 이메일이 갑니다
- AI가 제안서 작성에 실패하면 관리자에게 알림이 가고, 수동 조치가 필요합니다

## 5. 화면별 주요 기능

### 고객 화면

| 화면 | 할 수 있는 일 |
|------|-------------|
| 메인/공고 검색 | 입찰 공고 검색, 필터로 원하는 공고 찾기 |
| 공고 상세 | 공고 내용 확인, 필요 서류 목록 확인, 첨부문서 다운로드 |
| 입찰 자격 진단 | "우리 회사가 이 입찰에 참여할 수 있는지" AI가 사전 진단 |
| 입찰 신청 | 서비스 레벨 선택 후 참여 신청 |
| 서류 업로드 | 필요 서류를 하나씩 올리기, 진행률 확인 |
| 내 입찰 현황 | 내가 신청한 입찰 목록, 각 건의 진행 상태 확인 |
| 요금 안내 | 서비스 종류별 비용 확인 |
| 인증/서류 가이드 | USFK 입찰에 필요한 인증(SAM 등록 등) 취득 방법 안내 |

### 관리자 화면

| 화면 | 할 수 있는 일 |
|------|-------------|
| 입찰 관리 | 전체 입찰 현황 확인, 상태 변경, 문서 확인 |
| 문서 편집 | AI가 만든 제안서를 수정하고 최종 확정 |
| 문서 양식 관리 | 제안서 양식 등록/수정/삭제 |
| 수집 관리 | SAM.gov 수집 현황, 수동 수집 실행 |
| 회원 관리 | 등록된 고객 목록 관리 |

## 6. 이런 경우에는 어떻게 되나요? (FAQ)

**Q. SAM.gov에 새 공고가 올라오면 바로 알 수 있나요?**
→ 시스템이 하루에 4번 자동으로 확인합니다. 새 공고가 있으면 관리자에게 이메일로 알려줍니다.

**Q. 공고에 첨부된 문서가 있으면 어떻게 되나요?**
→ 시스템이 자동으로 다운로드합니다. 다운로드할 수 없는 경우에는 링크를 제공합니다.

**Q. AI가 만든 제안서가 마음에 안 들면?**
→ 관리자가 직접 수정할 수 있습니다. 또는 AI에게 다시 작성하도록 요청할 수 있습니다.

**Q. 입찰 마감일을 놓칠 수 있나요?**
→ 마감 7일 전, 3일 전, 1일 전에 자동으로 이메일 알림이 갑니다.

**Q. 우리 회사가 이 입찰에 참여할 자격이 되는지 어떻게 알 수 있나요?**
→ AI 자격 진단 기능으로 사전에 확인할 수 있습니다. 다만 이 결과는 참고용이며, 정확한 자격은 SAM.gov 기준을 따릅니다.

**Q. 서류를 일부만 올려도 되나요?**
→ 최종적으로는 필수 서류를 전부 올려야 다음 단계로 진행됩니다. 일부만 올리고 나중에 추가할 수 있습니다.

**Q. 한 공고에 두 번 신청할 수 있나요?**
→ 안 됩니다. 동일 공고에는 한 번만 신청할 수 있습니다.

**Q. 비용은 어떻게 되나요?**
→ 요금 안내 페이지에서 서비스 종류별 비용을 확인할 수 있습니다. 현재는 문의 후 결제이며, 향후 온라인 결제가 추가될 예정입니다.
