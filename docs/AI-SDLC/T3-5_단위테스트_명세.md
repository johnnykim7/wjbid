# SAM.gov Bidding Agency Platform 단위테스트 명세

> 설계 버전: 1.22 | 최종 수정: 2026-10-25 | 관련 CR: CR-126, CR-129, CR-131, CR-132, CR-135, CR-136, CR-137, CR-140, CR-141, CR-142, CR-143, CR-144, CR-146, CR-147, CR-152, CR-153, CR-155, CR-156, CR-157, CR-159, CR-160, CR-162, CR-164, CR-168, CR-169, CR-170

> 단계: 3. Detail Design | 코드 레벨 테스트 케이스 정의
>
> Sprint별·모듈별로 단위테스트 케이스를 정의한다.
> Claude Code가 이 문서를 보고 테스트 코드를 생성한다.
>
> **이 문서의 범위**: 코드 레벨 검증 (함수 호출 → 결과 확인)

---

## 작성 원칙

1. 테스트 케이스는 "상황 → 행동 → 기대결과" 형식으로 작성한다.
2. FSM 상태 전이는 **허용 전이 + 금지 전이** 모두 정의한다.
3. 이벤트 발행 테스트는 **발행 여부 + 페이로드** 검증을 포함한다.
4. 경계값, 에러 케이스를 반드시 포함한다.
5. 테스트 전략(CLAUDE.md)의 범위·모킹·커버리지 기준을 따른다.
