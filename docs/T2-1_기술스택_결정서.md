### AI 연동 (Aimbase) — CR-002 갱신

| 영역 | 항목 | 선택 | 선택 이유 | 대안 검토 |
|------|------|------|----------|----------|
| AI 플랫폼 | 오케스트레이션 | Aimbase (`59.8.160.12:8280`) | 조직 내 LLM 중앙 관리. Workflow DAG 기반 | 자체 LLM 직접 호출 |
| AI 플랫폼 | 인증 | System API Key (`X-API-Key`) | 테넌트+도메인앱 바인딩. JWT 불필요 | JWT 토큰 |
| AI 플랫폼 | 테넌트 | `bidding_system` / 도메인앱 `bidding` | Aimbase 멀티테넌시 격리 | — |
| MCP | 서버 전송 | **HTTP POST + SSE 이중 지원** | Aimbase가 SSE로 연결. 기존 HTTP POST 유지 | HTTP만 |
| MCP | SSE 구현 | Spring SseEmitter | spring-webmvc 내장. 추가 의존성 불필요 | MCP SDK SSE |
| AI 워크플로우 | 호출 방식 | `LLMPlatformClient` → Aimbase Workflow API | `POST /workflows/{id}/run` + 폴링 | Aimbase Chat API |
| 문서 출력 | 최종 파일 | Aimbase `generate_document` 도구 | RFP마다 포맷 다름(Word/PDF). LLM이 코드 생성+실행 | 플랫폼 iText/POI |
| RAG | MVP 범위 | 미사용 (향후 확장) | RFP 텍스트를 워크플로우 input으로 직접 전달 | Knowledge Source |
| AI 제거 | 기존 코드 | OpenAIAdapter 비활성화 | Aimbase 경유. 직접 LLM 호출 불필요 | — |
