## 1. 목적

WJbid 고객 포털(frontend/customer-portal)의 홈 밖 화면에 직접 기록된 색을 CR-127 이 정의하는 색 이름표(디자인 토큰)로 바꾼다.
색 이름표 한 곳의 값을 바꾸면 모든 고객 화면의 색이 함께 바뀌는 상태가 목표다.

사용자는 색을 아직 정하지 않았다(후보: 차콜과 주황, 먹색, 모카 갈색, 파랑). 따라서 이 CR 은 특정 색으로 바꾸는 작업이 아니라, 어떤 색으로 정해지든 한 곳에서 바뀌게 하는 작업이다.

## 4. 전환 원칙 (계약 수신 후 적용)

1. 색 값은 CR-127 계약의 이름표만 쓴다. 이 CR 에서 이름표를 새로 정의하지 않는다. 필요한 이름표가 계약에 없으면 CR-127 에 요청한다.
2. 같은 용도의 색은 같은 이름표로 모은다. gray 와 slate 가 같은 용도로 섞인 곳은 용도 기준으로 하나의 이름표에 대응시킨다.
3. 화면 구조, 배치, 문구는 바꾸지 않는다. 색 지정 방식만 바꾼다.
4. 팔레트 클래스와 이름표의 대응표는 계약 수신 후 이 문서 5장에 기록하고 그대로 적용한다.
